### 🎓 AI, NLP & Machine Learning

* 📄 [PixelRAG PDF Chatbot](https://lnkd.in/gUYf6m8y)

  A local multilingual document assistant developed with Python, FastAPI, Docling, Ollama, ChromaDB, and SQLite. It supports multiple PDF uploads, document selection, Bengali, English, and Banglish queries, voice input, page citations, evidence images, and combined question answering.

* 🧠 [NeuroScope AI](https://huggingface.co/spaces/Miraj74/Neuroscope)

  An agentic chatbot application developed with Python, Groq Cloud API, Gradio, LLM tool calling, web search, custom domain filtering, conversational memory, and structured response handling.

* 📑 **Document RAG & Automated Resume Parser**

  A document processing and semantic retrieval system using Docling, vector embeddings, cosine similarity, regular expressions, and NLP processing to extract structured candidate information from unstructured CV files.

* 📷 [Live Camera OCR System](https://github.com/mirazchowdhury/live-camera-ocr)

  A real time OCR application developed with Python, OpenCV, and Tesseract. It uses region masking, adaptive thresholding, noise filtering, contour detection, and efficient webcam frame processing.

* 📧 [Spam Mail Classifier](https://github.com/mirazchowdhury/spam_mail_classifier_git)

  A text classification system using Scikit Learn, TF IDF feature extraction, text normalisation, tokenisation, stop word removal, and classification metrics such as precision, recall, and F1 score.

<h2 align="center">📚 Publications & Manuscripts</h2>

### 🧠 Tiny LLMs for Efficient Bangla Cyberbullying Analysis via Knowledge Distillation and Quantization

**Status:** In Preparation / Under Review

* Developing compact language models containing approximately 10 million to 60 million parameters for Bangla cyberbullying and threat detection.
* Applying Knowledge Distillation using soft targets and hidden layer matching from teacher models such as Bangla BERT.
* Combining LoRA training with 8 bit dynamic quantization for efficient CPU inference.
* Evaluating model performance across multiple cyberbullying categories, including rare threat and harassment classes.
* Studying the balance between model size, inference speed, memory usage, and macro F1 performance.

### 💳 Design and Implementation of an Integrated RFID Based Campus Wide Payment Architecture

**Status:** Thesis Paper / Preprint

* Developed an embedded payment ecosystem using Raspberry Pi and RFID modules.
* Designed real time transaction reporting and offline caching mechanisms.
* Built relational database structures for balance synchronisation and transaction logging.
* Conducted concurrency testing to evaluate reliability during high transaction volumes.
